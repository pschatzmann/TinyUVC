Detailed Description

ESP32-S2/S3/P4 with the TinyUSB stack of the arduino-esp32 core (Tools > USB Mode > "USB-OTG (TinyUSB)").

The core builds the configuration descriptor from the interfaces enabled before USB.begin(). UVCDevice::begin() enables the camera and calls USB.begin(); it therefore fails if USB was already started - which the core does before setup() when "USB CDC On Boot" is enabled. Use "USB CDC On Boot: Disabled" (Serial is then UART0), and if you want a USB serial port in addition, declare a USBCDC object (see the examples).
