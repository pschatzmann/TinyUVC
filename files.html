 TinyUSBSim.hDesktop stand-in for the parts of the TinyUSB device API that UVCTinyUSB.h uses. The calls are recorded in UVCSimBus, where UVCHostSimulator (playing the USB host and the TinyUSB core) picks them up. Like this the same class driver code runs on the desktop as on the microcontroller
 UVCHostSimulator.hDesktop only: plays the USB host (and the TinyUSB core) for a UVCDevice, so the complete device side - descriptors, class driver, probe/commit and payload streaming - can be run and tested on a PC
 ▼ platform
 UVCPlatformDesktop.hDesktop platform: there is no USB device controller, the device is driven by UVCHostSimulator (desktop/UVCHostSimulator.h)
 UVCPlatformESP32.hESP32-S2/S3/P4 with the TinyUSB stack of the arduino-esp32 core (Tools > USB Mode > "USB-OTG (TinyUSB)")
 UVCPlatformTinyUSB.hThe generic TinyUSB platform layer, for every board that uses the Adafruit TinyUSB Library (Adafruit_USBD_Device): RP2040/RP2350 with Tools > USB Stack > "Adafruit TinyUSB", STM32 (OTG_FS, e.g. F4/F7/H7), SAMD, nRF52 - and optionally the ESP32 (TINYUVC_USE_ADAFRUIT_TINYUSB). The camera is added as an additional interface next to the other interfaces of the device (e.g. the USB serial port)
 UVCConfig.hCompile-time limits and defaults of TinyUVC. Every value can be overridden with a build flag (-DTINYUVC_xxx=...) or a \#define before the first \#include "TinyUVC.h"
 UVCConvert.hConversion of raw pixel formats to YUY2 (YUV 4:2:2, Y0 U Y1 V), pixel pair by pixel pair, so it can run while a frame is being sent. Uses BT.601 limited range integer math
 UVCDefs.hUSB Video Class 1.1 constants and the basic TinyUVC data types
 UVCDescriptor.hBuilds the USB descriptors of a UVC 1.1 camera function: an Interface Association, a VideoControl interface (camera terminal -> output terminal) and a VideoStreaming interface with one bulk IN endpoint, offering MJPEG and/or YUY2 in several resolutions
 UVCDevice.hThe USB Video Class device: descriptors, probe/commit negotiation and streaming of frames. Independent of the USB stack: the TinyUSB glue (UVCTinyUSB.h) and the platform layer (platform/UVCPlatform*.h headers) connect it to the hardware
 UVCLogger.hMinimal printf-style logger. On Arduino it writes to a Print (default: Serial), on the desktop to stderr
 UVCMemory.hMemory for frame sized buffers, taken from PSRAM where the board has it: ESP32 with PSRAM enabled (Tools > PSRAM), and RP2350 boards with PSRAM (arduino-pico defines RP2350_PSRAM_CS). Elsewhere it is normal heap memory
 UVCPayload.hSplits one video frame into UVC payloads (payload header + data)
 UVCTinyUSB.hConnects UVCDevice to TinyUSB as an application class driver (usbd_app_driver_get_cb()). This works with every TinyUSB build - the one in the ESP32 Arduino core and the Adafruit TinyUSB Library - whether its own video class (CFG_TUD_VIDEO) is compiled in or not, because application drivers are asked first
 TinyUVC.hTinyUVC: header-only USB Video Class (UVC) device - turns a microcontroller into a USB webcam
 TinyUVCAudioTools.hIntegration with the video classes of arduino-audio-tools (https://github.com/pschatzmann/arduino-audio-tools):
 TinyUVCCamera.hStreams a camera of the TinyCamera library (https://github.com/pschatzmann/TinyCamera) as USB webcam: esp32-camera sensors (OV2640, OV3660, OV5640, ...), ESP32-P4 MIPI-CSI, RP2040 (PicoCamera), STM32 DCMI and the desktop (webcam or test pattern)
