Detailed Description

Integration with TinyGPU (https://github.com/pschatzmann/TinyGPU): UVCDisplayDriver is a TinyGPU DisplayDriver whose "display" is the webcam. Everything that is rendered into a TinyGPU surface (2D drawing, text, sprites, WireFrame3D) and written with writeData() shows up as video on the PC.

UVCDevice uvc;
UVCDisplayDriver<RGB565> display(uvc);
FrameBufferRGB565 framebuffer(320, 240, FontRGB565);
void setup() {
display.addResolution(UVCFormat::MJPEG, 320, 240, 15);
display.addResolution(UVCFormat::YUY2, 160, 120, 15);
display.begin();
framebuffer.begin();
}
void loop() {
if (display.sizeChanged(framebuffer.width(), framebuffer.height()))
framebuffer.resize(display.width(), display.height());
framebuffer.clear(RGB565(255, 255, 255));
... // draw
display.writeData(framebuffer); // waits for the next frame slot
}

Uncompressed YUY2 needs 2 bytes per pixel: full speed USB (about 1 MB/s) carries 160x120 at 15+ fps, but 320x240 only at about 5 fps. For bigger pictures offer MJPEG, the frames are then compressed:

  • ESP32 (RGB565): with the JPEG encoder of esp32-camera, which comes with the arduino-esp32 core (fmt2jpg_cb(), img_converters.h).
  • other boards, and RGB888 surfaces: with TinyJPEG (https://github.com/pschatzmann/TinyJPEG). Include TinyJPEGEncoder.h before this header (in Arduino the library is only found if the sketch includes it). Its encoder supports frames up to JE_MAX_WIDTH pixels wide (default 320): define it before the include for bigger frames. Define TINYUVC_NO_JPEG to switch MJPEG off.
