 UVCPlatformTinyUSB.h
 The generic TinyUSB platform layer, for every board that uses the Adafruit TinyUSB Library (Adafruit_USBD_Device): RP2040/RP2350 with Tools > USB Stack > "Adafruit TinyUSB", STM32 (OTG_FS, e.g. F4/F7/H7), SAMD, nRF52 - and optionally the ESP32 (TINYUVC_USE_ADAFRUIT_TINYUSB). The camera is added as an additional interface next to the other interfaces of the device (e.g. the USB serial port).
