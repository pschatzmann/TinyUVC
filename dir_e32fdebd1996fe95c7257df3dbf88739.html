Files

 UVCConfig.h
 Compile-time limits and defaults of TinyUVC. Every value can be overridden with a build flag (-DTINYUVC_xxx=...) or a \#define before the first \#include "TinyUVC.h".
 
 UVCConvert.h
 Conversion of raw pixel formats to YUY2 (YUV 4:2:2, Y0 U Y1 V), pixel pair by pixel pair, so it can run while a frame is being sent. Uses BT.601 limited range integer math.
 
 UVCDefs.h
 USB Video Class 1.1 constants and the basic TinyUVC data types.
 
 UVCDescriptor.h
 Builds the USB descriptors of a UVC 1.1 camera function: an Interface Association, a VideoControl interface (camera terminal -> output terminal) and a VideoStreaming interface with one bulk IN endpoint, offering MJPEG and/or YUY2 in several resolutions.
 
 UVCDevice.h
 The USB Video Class device: descriptors, probe/commit negotiation and streaming of frames. Independent of the USB stack: the TinyUSB glue (UVCTinyUSB.h) and the platform layer (platform/UVCPlatform*.h headers) connect it to the hardware.
 
 UVCLogger.h
 Minimal printf-style logger. On Arduino it writes to a Print (default: Serial), on the desktop to stderr.
 
 UVCPayload.h
 Splits one video frame into UVC payloads (payload header + data).
 
 UVCTinyUSB.h
 Connects UVCDevice to TinyUSB as an application class driver (usbd_app_driver_get_cb()). This works with every TinyUSB build - the one in the ESP32 Arduino core, the Adafruit TinyUSB Library and the Pico SDK of arduino-pico - whether its own video class (CFG_TUD_VIDEO) is compiled in or not, because application drivers are asked first.
