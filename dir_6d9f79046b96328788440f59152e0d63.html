 TinyUSBSim.h
 Desktop stand-in for the parts of the TinyUSB device API that UVCTinyUSB.h uses. The calls are recorded in UVCSimBus, where UVCHostSimulator (playing the USB host and the TinyUSB core) picks them up. Like this the same class driver code runs on the desktop as on the microcontroller.

 Desktop only: plays the USB host (and the TinyUSB core) for a UVCDevice, so the complete device side - descriptors, class driver, probe/commit and payload streaming - can be run and tested on a PC.
