Detailed Description

VideoOutput that sends every frame (write() calls up to flush()) to a UVCDevice. Two frame buffers are used: one is sent while the next one is written.

Writers that deliver one complete frame per write() without calling flush() (e.g. MJPEGEncoder) are supported as well: a complete JPEG written in one call is sent right away, for other formats use setFlushOnWrite(true).

UVCDevice uvc;
UVCVideoOutput out(uvc, PixelFormat::MJPEG);
MJPEGEncoder encoder(out); // RGB565 -> JPEG -> webcam
