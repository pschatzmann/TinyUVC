Detailed Description

Connects a TinyCamera to a UVCDevice.

Offers MJPEG if the camera config uses PIXFORMAT_JPEG (sensors with a JPEG encoder), otherwise YUY2, which is converted on the fly from the camera's RGB565 (or YUV422 / grayscale) frames. When the host selects a different resolution or format, the camera is reconfigured.

UVCDevice uvc;
UVCCamera camera(uvc);
void setup() {
camera_config_t cfg = TinyCamera::defaultConfig();
setPinsAIThinker(cfg);
camera.addFrameSize(FRAMESIZE_QVGA);
camera.addFrameSize(FRAMESIZE_VGA);
camera.begin(cfg); // also starts uvc
}
void loop() { camera.copy(); }
