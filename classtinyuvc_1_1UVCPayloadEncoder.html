Detailed Description

Produces the UVC payloads of one frame. Each payload starts with a 2 byte header (6 bytes with a presentation time stamp) that carries the frame id bit (FID, toggled per frame) and, in the last payload of the frame, the end of frame bit (EOF).

The source data is only read while fill() runs: once done() is true the caller may reuse the frame buffer. Raw pixel formats are converted to YUY2 on the fly.
