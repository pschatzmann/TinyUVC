Enumeration Type Documentation

◆ PixelFormat

enum class tinyuvc::PixelFormat : uint8_t
strong

Pixel format of the frame data handed to UVCDevice::writeFrame(). MJPEG (a JPEG image) is sent as is. (Not named JPEG: STM32H7 headers define a JPEG macro.) YUY2 is sent as is (YUY2). All other formats are converted to YUY2 on the fly, while they are sent, so they need no extra frame buffer.

Enumerator
MJPEG 

one complete JPEG image (for UVCFormat::MJPEG)

YUY2 

packed YUV 4:2:2, byte order Y0 U Y1 V

RGB565_LE 

16 bit RGB565, little endian (low byte first)

RGB565_BE 

16 bit RGB565, big endian (high byte first, esp32-camera)

RGB888 

24 bit, byte order R G B

BGR888 

24 bit, byte order B G R

GRAY8 

8 bit luminance
