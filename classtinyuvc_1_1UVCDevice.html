Detailed Description

USB Video Class (UVC 1.1) device - a USB webcam.

Declare the formats/resolutions/frame rates you can deliver, call begin(), then hand over frames with writeFrame() whenever isReady():

UVCDevice uvc;
void setup() {
uvc.addResolution(UVCFormat::MJPEG, 320, 240, 15);
uvc.begin();
}
void loop() {
if (uvc.isReady()) uvc.writeFrame(jpeg, jpegLen, PixelFormat::MJPEG);
}

@ MJPEG
one complete JPEG image (for UVCFormat::MJPEG)

The frame data must stay valid until isReady() is true again (it is copied payload by payload into the transfer buffer while it is sent). Frames are sent over a bulk endpoint, which all major operating systems support (Linux, Windows, macOS).

Only one UVCDevice can be active.

bool tinyuvc::UVCDevice::writeFrame ( const uint8_t *  data,
size_t  len,
PixelFormat  fmt 
)
inline

Sends a frame. Returns false (and the frame is not sent) if the device is not ready or the frame does not fit the format the host selected:

  • MJPEG: fmt must be PixelFormat::MJPEG
  • YUY2: any raw format with exactly width * height pixels; it is converted to YUY2 while it is sent

The data must stay valid until isReady() is true again.
