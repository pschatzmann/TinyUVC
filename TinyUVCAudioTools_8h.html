Detailed Description

Integration with the video classes of arduino-audio-tools (https://github.com/pschatzmann/arduino-audio-tools):

  • UVCVideoOutput: a VideoOutput, so everything that writes frames to a VideoOutput - VideoPlayer (AVI/MP4 files), MJPEGEncoder, the video decoders (H264, MPEG1, MJPEG -> RGB565/YUV422) - can feed the webcam.
  • UVCVideoCopy: streams the frames of a VideoFrameSource (e.g. CameraFrameSourceTinyCamera) to the webcam.

The video classes of arduino-audio-tools use FreeRTOS: on RP2040/RP2350 select Tools > Operating System > "FreeRTOS SMP" and include "AudioTools/Concurrency/RTOS.h" after AudioTools.h, on STM32 install the STM32FreeRTOS library.
