Detailed Description

Compile-time limits and defaults of TinyUVC. Every value can be overridden with a build flag (-DTINYUVC_xxx=...) or a \#define before the first \#include "TinyUVC.h".

◆ TINYUVC_PAYLOAD_SIZE

#define TINYUVC_PAYLOAD_SIZE   16384

Max size of one UVC payload transfer (header + data) in bytes. It is reported to the host as dwMaxPayloadTransferSize and is the size of the one transfer buffer the device allocates. Bigger values reduce the idle time between transfers. It is rounded to a multiple of the endpoint's max packet size and limited to 32 packets (2048 bytes full speed, 16384 bytes high speed), the URB size of Linux. Change it with UVCDevice::setPayloadSize().
