Detailed Description

Desktop only: plays the USB host (and the TinyUSB core) for a UVCDevice, so the complete device side - descriptors, class driver, probe/commit and payload streaming - can be run and tested on a PC.

The host side follows the Linux uvcvideo driver: the bulk endpoint is read with URBs of at most 32 packets, a payload ends with a short packet (or zero length packet) or when dwMaxPayloadTransferSize bytes were received, frames are delimited by the FID/EOF header bits, payloads that are out of sync are dropped and uncompressed frames of the wrong size are flagged as errors.
