Detailed Description

Connects UVCDevice to TinyUSB as an application class driver (usbd_app_driver_get_cb()). This works with every TinyUSB build - the one in the ESP32 Arduino core and the Adafruit TinyUSB Library - whether its own video class (CFG_TUD_VIDEO) is compiled in or not, because application drivers are asked first.

TinyUSB knows only one usbd_app_driver_get_cb(): this header defines it unless TINYUVC_NO_APP_DRIVER is defined. Define TINYUVC_NO_APP_DRIVER in every additional .cpp file that includes TinyUVC.h, or if you need to combine TinyUVC with another application driver: then return tinyuvc::tusb_glue::driver() from your own usbd_app_driver_get_cb().
