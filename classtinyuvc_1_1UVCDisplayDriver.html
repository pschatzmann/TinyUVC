Detailed Description

template<typename RGB_T = tinygpu::RGB565>
class tinyuvc::UVCDisplayDriver< RGB_T >

TinyGPU DisplayDriver that sends the written surfaces as webcam frames to the USB host: uncompressed (YUY2), or compressed with TinyJPEG (MJPEG) - whichever format the host selected.

The surface is copied (YUY2) or compressed (MJPEG) into a frame buffer, from PSRAM where available (see UVCMemory), so the sketch can render the next frame while the previous one is still being sent. writeData() waits until the device can take a new frame and, with pacing (default), until the frame interval the host selected has passed: the render loop then runs at the frame rate of the webcam.

width()/height() report the resolution the host selected; resize your surface when it changes (see the TinyGPUWireframeWebcam example). Supported color types: RGB565 and RGB888.
