Detailed Description

Memory for frame sized buffers, taken from PSRAM where the board has it: ESP32 with PSRAM enabled (Tools > PSRAM), and RP2350 boards with PSRAM (arduino-pico defines RP2350_PSRAM_CS). Elsewhere it is normal heap memory.

The USB transfer buffer of UVCDevice is not allocated here: the USB DMA needs internal RAM. Frames that are written to UVCDevice::writeFrame() can be anywhere (PSRAM too), because they are copied payload by payload into the transfer buffer.
